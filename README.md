# Dossenix Legal Infos

Static GitHub Pages site for the general Terms of Service and Privacy Policy of
Dossenix bots, automations, integrations, support services, and Fiverr/custom
client work.

Repository: `Dossenix/dossenix-legal-infos`

Expected GitHub Pages URL:
`https://dossenix.github.io/dossenix-legal-infos/`

Direct links for bot/platform fields:

- Terms: `https://dossenix.github.io/dossenix-legal-infos/terms.html`
- Privacy: `https://dossenix.github.io/dossenix-legal-infos/privacy.html`

## Files

- `index.html` contains the English and Italian legal pages.
- `styles.css` contains the responsive layout and visual style.
- `script.js` controls the EN/IT language switch and remembers the last choice.

## Publish on GitHub Pages

1. Push these files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the branch and `/ (root)` folder.
6. Save. GitHub will publish the site after the Pages build finishes.

## Before Publishing

Review the legal text and adapt it to the exact bots, platforms, contact
methods, retention periods, owner details, and client workflows you actually
use. This template is not legal advice.
